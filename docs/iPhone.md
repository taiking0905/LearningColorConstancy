# iPhone データセット

## 1. 概要

本研究では、iPhone 13 を用いて撮影した独自のRAW画像データセットを使用する。  
本データセットは **150枚のDNG形式画像** から構成される。    
アプリはRAW画像取得するためのみに使用しているので自作も可能だと思う。   

- Device: iPhone 13  
- Application: [ProCamera](https://apps.apple.com/jp/app/procamera-/id694647259)
- Image format: 12bit DNG  
- Resolution: 4032 × 3024  

---

## 2. 撮影条件

撮影は原則オートモードで行ったが、高反射率の被写体に対してはシャッタースピードを調整した。

| 項目 | 設定値 | 備考 |
|------|--------|------|
| ISO | 100 | 固定 |
| シャッタースピード | Auto | 高反射被写体は調整 |
| アプリ | ProCamera | iPhone 13 使用 |
| 保存形式 | 12bit DNG | RAW形式 |
| 撮影場所 | 屋内 / 屋外 / 植物 | 各50枚 |
| 撮影日時 | 11月 10:00–17:00 | 光源混在を回避 |
| 照明色取得 | WhiBal Gray Card | 白・灰・黒の3色 |

---

## 3. 正解値取得方法

各画像には White Balance 用グレーカード（WhiBal Gray Card）を含めた。

本研究では照明色の正解値取得を目的としているため、  
MacBeth Color Checker のような多色チャートは使用せず、  
グレーカード1枚で十分と判断した。

---

## 4. 飽和画素に基づく信頼性判定

RAW画像における高輝度飽和画素の割合を基に、データの信頼性を判定した。

- 12bit表現
- 画素値 ≥ 3300
- 全画素の 3%以上

を満たす画像は露出不良の可能性が高いと判断し、  
学習および評価から除外した。

この判定はPC上で自動実行される。

この閾値は理論的根拠に基づくものではなく、  
明らかな露出異常を除外するための経験的かつ保守的基準である。
